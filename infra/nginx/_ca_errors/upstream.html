应用进程暂时不可用（502 / 504）

Nginx 无法连接到 cloudalbum-api。如果刚刚启用或禁用了模块，最常见的原因是配置校验失败：进程以退出码 78 退出，systemd 不会自动重启它。

在实例上运行：

sudo -u cloudalbum CLOUDALBUM_ENV_DIR=/etc/cloudalbum node /opt/cloudalbum/backend/dist/cli.js check-config
journalctl -u cloudalbum-api -n 50 --no-pager

按输出中的修复命令处理后执行 sudo systemctl restart cloudalbum-api cloudalbum-worker；或在运维机上执行 scripts/module status --repair。
