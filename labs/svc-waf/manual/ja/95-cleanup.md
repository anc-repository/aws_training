セッションの終了時、プラットフォームが自動で回収します。まず空の `WebAclArn` で cdn スタックを更新して**関連付けを解除し**（ディストリビューションの再デプロイに数分）、その後 us-east-1 の Web ACL と IP セットを削除します。関連付けられたままの Web ACL は削除できません。

- WAF のロググループ `{{ var.logGroup }}` は **us-east-1** にあり、データ保護の取り決めにより**保持**されます。自分で Logs Insights で検索するときは us-east-1 に切り替えることを忘れないでください。
- 別の実験のために `WAF_LAB_ALLOW_CIDR` を設定した場合は、終了前に空にしてください。これは Allow アクションで、そのアドレスにすべてのルールをスキップさせてしまいます。
