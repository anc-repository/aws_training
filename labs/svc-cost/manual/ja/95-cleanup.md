- 回収処理では、2 つの予算、予算アクション、カナリアロール、cost トピックを削除します（予算はグローバルリソースのため、回収処理は us-east-1 側で照合します）。
- **コスト配分タグは有効のまま**で、カードとともに無効にはしません。無効にすると、Cost Explorer のタグ別の履歴集計に空白ができてしまいます。
- `cost-rates.yaml` はラボ用インスタンスのデータボリュームにあり、インスタンスとともに削除されます。書き写した単価を残したい場合は、終了前に自分でコピーしてください。
- Cost Explorer API は呼び出すたびに課金されます。このカードで手動更新するのは最大 1 回です。何度も更新しないでください。
- プラットフォームの `atl-platform-guard` 予算はこのカードのものではありません。変更しないでください。
