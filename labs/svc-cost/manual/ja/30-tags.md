プロジェクト予算は、コスト配分タグ `Project=CloudAlbum` で費用を絞り込みます。すべてのモジュールスタックにはスタックレベルのタグ `Project`、`Module` が付いていますが、ユーザー定義タグは
Billing でコスト配分タグとして**有効化**しない限り、コストデータのグループに現れません。

```bash {runsOn=workstation}
aws ce list-cost-allocation-tags --tag-keys Project Module --region us-east-1
```

有効になっていない（または一覧に見つからない）場合は、プラットフォームアクションを実行します（その場では反映されません）。

::platform-action{id=cost-activate-tags}

:::expected
`Project` の `Status` が `Active` です。まだ反映されていなくても続けられます。その場合プロジェクト予算はずっと 0 と表示されますが、それ自体が観察ポイントです。
:::

:::why
新しいタグキーは有効化できる一覧に現れるまで時間がかかり、有効化後も反映まで時間がかかります。また、有効化前の費用にはさかのぼりません（具体的な時間は公式ドキュメントを確認してください）。
AWS Organizations では管理アカウントしか有効化できません。そのため、このステップはラボの前日に済ませておくのが理想です。
:::

:::tip
Cost Explorer の API はリクエストごとに課金される場合があり、プラットフォームのチェック結果は 30 分間キャッシュされます。上のコマンドをターミナルで何度も実行しないでください。
:::

::checks
