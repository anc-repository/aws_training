## このラボでできたこと

- 写真を EBS データボリュームから S3 に移し、アップロードをブラウザーからの直接アップロードに変えました。ラボ用インスタンスはもうアップロードのバイトを受け持ちません。
- バケットのセキュリティベースライン（BPA、ACL の無効化、HTTPS のみ許可、デフォルト暗号化）とコストの設定（バージョニング、ライフサイクル）を読み解きました。

## 試験ポイントの振り返り

- 署名付き URL の有効期間と署名に使う認証情報：一時的な認証情報で署名した URL は、認証情報の失効とともに早く無効になる。
- Block Public Access、`BucketOwnerEnforced`、バケットポリシーの `aws:SecureTransport`。SSE-S3、SSE-KMS と Bucket Key。
- バージョニング + ライフサイクル。ストレージクラスの最短保存期間と最小課金サイズ。
- S3 イベント通知と EventBridge の違い。S3 のゲートウェイエンドポイントは時間課金されない。
