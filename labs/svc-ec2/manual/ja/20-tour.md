アプリのプレビューでアルバムを一通り使いながら、ブラウザーの開発者ツールの Network パネルを開いておきます。

1. アカウントを登録し、「我的邮件」（`/me/outbox`）にある確認メールを開いて確認を済ませます（L0 では実際にはメールを送信しません）。
2. 写真を何枚かアップロードし、サムネイルができるのを待ってから、「いいね」やコメントをします。
3. Network パネルで任意の `/api/` リクエストを選び、レスポンスヘッダー `X-CloudAlbum-Path` と `Server-Timing` を見ます。

:::expected
`X-CloudAlbum-Path` は `entry=nginx` で、ストレージのセグメントはローカルディスク、サムネイルのセグメントは `inline` です。`Server-Timing` には各ポートの所要時間が出ます。
すべての機能がこの 1 台のマシンで完結しています。
:::

:::tip
`X-CloudAlbum-Path` は、この後のすべてのカードで「証拠」になります。モジュールを 1 つ有効にすると、対応するセグメントがローカル実装から AWS のサービスに変わります。
:::

::checks
