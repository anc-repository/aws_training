## 你做到了什么

- 从自签名证书走到受信任的 ACM 证书：ACME 分支装进 Nginx，回退分支挂在 CloudFront 上（证书在 us-east-1）。
- 用服务端证据（实验机本机握手、平台按域名访问时核对证书 SAN、ACM 控制面中的证书）确认了证书真的生效。
- 分清了“考试结论”和“2026 新能力”。

## 考点回顾

- ACM 公有证书用于集成服务时免费、自动续期，私钥不可导出；DNS 验证与邮件验证；验证记录必须保留才能续期。
- 证书区域：CloudFront 与 Cognito 托管登录页自定义域名用 us-east-1；ALB 与区域型 API Gateway 用资源所在区域。
- 导入的证书要手动续期；ACM Private CA 用于内部证书。
- SNI 与“一个监听器挂多张证书”；ALB 到目标可以再加密，ALB 不校验目标证书。
- HSTS；在边缘终止 TLS 能降低远端用户的握手延迟。
