## このラボでできたこと

- アルバムに固定のドメイン名を付けました。メール、共有リンク、`APP_BASE_URL` はもう IP に縛られません。
- IP 変更の訓練で「名前は固定、宛先は交換可能」を証明しました。古い IP のリンクはずっと失敗し、ドメイン名のリンクは TTL 程度の時間で復旧しました。
- Alias が A レコードを直接返すこと、ゾーンの頂点には CNAME を作れないことを自分の手で確かめました。

## 試験ポイントの振り返り

- パブリックとプライベートのホストゾーン。プライベートホストゾーンには、VPC で DNS サポートと DNS ホスト名を有効にする必要があります。
- A、AAAA、CNAME、Alias：ルートドメインには Alias しか使えません。AWS リソースを指す Alias のクエリは無料です。Alias は IP や Elastic IP を指せません。
- TTL とキャッシュ：移行の前に TTL を下げておきます。
- ルーティングポリシー：シンプル、加重、レイテンシー、フェイルオーバー、位置情報、地理的近接性、複数値回答、IP ベース。ヘルスチェックの種類と Evaluate Target Health。
- ドメインの登録と DNS ホスティングは別物です。NS 委任。ホストゾーンを削除して作り直すと新しい NS になります。
