包含的卡片

    核对报告：选择持有人提供的报告 JSON，浏览器按 RFC 8785 规范化后计算 SHA-256 并与证书中的报告摘要比较，文件不会上传。请使用持有人在证书详情中下载的“核验用报告 JSON”；打码导出的报告或更新过的版本会显示不一致。

    如何独立核对

    把上面的公钥指纹与持有人在其公开主页（例如 GitHub 个人页）上公布的指纹对照。验证完全在你的浏览器中完成，不需要登录：页面读取本实例的公钥与签名的吊销列表，用浏览器内置的 WebCrypto 验证 ES256 签名。

    粘贴证书或选择文件

    也可以选择证书文件（.jws）或离线验证包（.json）。
