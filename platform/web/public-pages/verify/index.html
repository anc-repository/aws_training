ATL 修了証の検証

AWS の公式認定ではなく、セルフホストの ATL インスタンスが発行した修了証明です。

この証明は、受講者自身の AWS アカウントにデプロイされたセルフホストの AWS Training Lab インスタンスが自動で発行したものです。そのインスタンスが、保有者が記載のラボを完了したことを記録したことを示します。署名により、内容が改ざんされていないこと、そのインスタンスの署名鍵で発行されたことを確認できます。AWS の公式認定ではなく、AWS Certified Solutions Architect – Associate やその他の AWS 認定資格を示すものでもありません。発行者と保有者が同一人物の場合があり、プラットフォームのデータと鍵はアカウント所有者が管理しています。検証結果が示すのは「このインスタンスがこの内容を発行した」ことだけで、発行手続きの独立性は示しません。

含まれるカード

    レポートの照合：保有者から受け取ったレポート JSON を選ぶと、ブラウザーが RFC 8785 で正規化して SHA-256 を計算し、修了証のレポートダイジェストと比較します。ファイルはアップロードされません。保有者が修了証の詳細からダウンロードした「照合用レポート JSON」を使ってください。マスクしてエクスポートしたレポートや更新後の版は不一致になります。

    独自に確認する方法

    上の公開鍵フィンガープリントを、保有者が公開プロフィール（GitHub のプロフィールなど）に載せているフィンガープリントと照らし合わせてください。検証はすべてブラウザー内で行われ、ログインは不要です。このページはインスタンスの公開鍵と署名付き失効リストを読み込み、ブラウザー組み込みの WebCrypto で ES256 署名を検証します。

    修了証を貼り付けるか、ファイルを選択

    修了証ファイル（.jws）やオフライン検証パッケージ（.json）も選べます。

    セルフホストの ATL ラボプラットフォーム（AWS 非公式）。プラットフォームをアンインストールすると、このページと公開された修了証ファイルは使えなくなります。修了証ページにあるオフライン検証パッケージを使ってください。
